Anthropic 这篇关于Agent Memory的文章提出了对于Agent架构设计非常重要的两个思路： Dreaming + Memory Evaluation，Dreaming 使得Agent像人一样在空闲时主动整理过去的记忆并抽取规律，甚至自主生成wiki；Memory Evaluation 则指出并不是所有的历史记录都值得被保存，还应该评估记忆的真实性、时效性、可复用性，以及能否真正改善 Agent 的任务表现。
